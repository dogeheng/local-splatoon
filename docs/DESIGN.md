# 泼色竞技场 · 实现设计说明（v0.1）

本文档是《Web 联机游戏技术选型报告》在用户确认后的落地版本，记录已拍板的决策与可调参数。所有数值的唯一来源是 `shared/constants.ts`，本文仅做说明。

## 已确认的决策

| 项目 | 决策 |
|---|---|
| 项目形式 | 独立本地项目；服务器运行在本机，局域网内其他电脑用浏览器访问 `http://<本机IP>:8080` |
| 平台 | 仅电脑（键盘 + 鼠标），不做手机 |
| 规则参考 | 斯普拉遁 3「占地对战」，角色、名称、美术全部原创 |
| 队伍 | 两队对抗（橙队 / 青队），每队最多 2 人，支持 1v1、2v2、2v1；人少一方补墨与复活更快 |
| 视角 | 俯视 2.5D，整个场地一屏可见，鼠标指向瞄准 |
| 时长 | 默认 3 分钟，房主可改为 2 分钟；最后 1 分钟音乐加速 |
| 人数 | 最多 4 名玩家 + 4 名观战 |
| 语言 | 仅中文界面 |

## 操作

| 按键 | 动作 |
|---|---|
| WASD | 移动 |
| 鼠标 | 瞄准 |
| 左键（按住） | 喷墨射击，消耗墨水 |
| Shift（按住） | 潜游形态：己方墨水中高速移动并快速补墨、对敌方隐身；不能射击 |
| 右键 | 向鼠标位置投掷墨水炸弹（消耗 70% 墨水） |
| E | 大招「墨潮」：能量满时释放，6 秒内无限墨水、射速与涂色范围提升，释放瞬间向四周爆出一圈墨水 |
| Tab | 查看队伍状态 |
| F3 | 网络调试面板 |

## 规则要点

1. 地面被划分为 0.25 × 0.25 的涂色格，墨水落点按圆形涂色；障碍物不可涂，不计入总面积。
2. 只有射击、炸弹、大招、被击倒时的爆墨会改变地面，走路不会涂色。
3. 站在敌方墨水中：减速、持续掉血（不会因此被击倒）、不能潜游加速。
4. 生命值 100，主武器每发 34 伤害（3 发击倒），1 秒未受伤后快速回血。
5. 被击倒后在击倒者的颜色中爆出一摊墨水，约 3 秒后在己方出生点复活，并有 1.5 秒保护；大招能量减半。
6. 出生点有屏障，敌方玩家和敌方墨弹无法进入。
7. 对局中不显示实时百分比（与原作一致），结束后统一揭晓两队涂地面积，面积大者获胜。
8. 某队全部玩家离线持续 10 秒，该队判负（弃权）。

## 网络同步

- 服务器权威，60Hz 固定步长模拟，30Hz 快照。
- 客户端只发送输入 `[seq, 移动x, 移动z, 瞄准角, 投掷距离, 按键位]`，每步一条。
- 自己的角色用 `shared/sim.ts` 的同一份步进函数预测，收到快照后丢弃已确认输入并重放未确认输入，误差用视觉偏移淡出。
- 子弹散布由 `hash(座位, 输入序号)` 决定，客户端预测的弹道与服务器完全一致。
- 他人角色按“速度 × 快照年龄”投影到当前时刻并平滑显示。
- 涂色、伤害、击倒、复活、胜负全部由服务器决定；客户端只渲染。

## 生命周期

- 座位令牌存在 `sessionStorage`，刷新或断线 60 秒内自动恢复原座位。
- 对局中加入的人进入观战，下一局开始前若有空位自动入座。
- 房主离开时自动移交；空房间 60 秒后销毁。
